Alignment
=========

Spectrogram-guided forced alignment (SGPA) maps transcript tokens onto audio
time ranges. These helpers live under :mod:`nlp_shap.alignment` and require the
optional ``[audio]`` extra (``torch``, ``torchaudio``, ``transformers``,
``librosa``, ``soundfile``).
